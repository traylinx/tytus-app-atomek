# Atomek Skill: Tytus Agent Team Use Cases

Use when the user asks what Tytus can do or wants workflow examples.

Cover these patterns:
- repo repair with OpenClaw critique, local agent implementation, Hermes review
- document packages with mission sources and markdown output
- creative production with JULI3TA, Blender, Remotion, and shared assets
- research watch with pod gathering and local synthesis
- app automation through installed app skills

Always connect the workflow to mission folders, shared resources, and approval gates.
