# Atomek Skill: Local Agent Job

Run allowlisted local agent CLIs through Tytus tray local jobs.

Rules:
- Discover tools with `host.local.listTools()`.
- Start jobs with `host.local.runJob()` only for allowlisted tools.
- Stream via `host.local.streamJob()`.
- Treat job output as advisory until converted into an artifact or preview edit.
- No hardcoded model IDs; each CLI uses its own global/local configuration.
- No arbitrary shell generated by model output.

Safe initial tools:
- codex: noninteractive read-only exec
- claude: noninteractive print in plan mode
- opencode: run command
- gemini/qwen: noninteractive plan mode
- aider: dry-run mode
- pi/kimi: local configured wrapper via shell function/alias only
