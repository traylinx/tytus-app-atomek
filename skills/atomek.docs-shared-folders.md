# Atomek Skill: Shared Folders and Mission Handoff

Use when the user asks how to share files between local agents, pods, Tytus apps, or machines.

Rules:
- Explain `~/Tytus/Shared`, mission folders, pod `/app/workspace`, inbox/outbox, and Garage bindings when relevant.
- Prefer append-only evidence and one-writer-per-file conventions.
- Put proposed edits in `proposals/` and final handoffs in `OUTBOX.md`.
- Warn against raw credentials and broad blind write access in shared folders.
